Pengaturan Koneksi

Hubungkan halaman ini ke Google Sheet kamu lewat Apps Script Web App.

1. Buat Google Sheet baru, lalu buka Extensions > Apps Script dan paste kode backend (file terpisah yang sudah disiapkan).
2. Ganti SECRET_KEY di kode itu dengan kata sandi rahasiamu sendiri.
3. Jalankan fungsi setupSheets() sekali untuk membuat semua tab otomatis.
4. Klik Deploy > New deployment > Web app, akses "Anyone", lalu copy URL-nya ke bawah ini.

Tersimpan di browser ini ✓

Catatan: URL & key ini disimpan hanya di browser kamu (localStorage), tidak dikirim ke server manapun selain Google.
